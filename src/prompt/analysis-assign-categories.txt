% ${reasons} は step2 の箇条書き評価根拠を埋め込む。
% ${category_definition} は評価観点定義を埋め込む。
% ${context_text} は評価根拠の出典となる語り本文（文脈）を埋め込む。
以下の評価根拠にカテゴリを割り当ててください。

# 元文脈（参照用）
${context_text}

# 評価根拠（箇条書き）
${reasons}

# 評価観点カテゴリ定義
${category_definition}

# タスク
- 各評価根拠に対して、該当する評価観点カテゴリを割り当てる。
- 該当カテゴリがない場合は「その他」を割り当てる。

# 出力形式（厳守）
[カテゴリ1] 評価理由1
[カテゴリ1, カテゴリ2] 評価理由2

# 制約
- 見出しや前置きは不要。
- 1行に1つの評価理由のみを書く。`->`が次の行で示されている場合、それは前の行と一体の評価項目とみなして良い。
- カテゴリ名は定義文の表記に合わせる。
- カテゴリ割り当ては、評価根拠の文面だけでなく「元文脈」の意味も踏まえて判断する。
- 評価理由部分は、入力の根拠を改変しすぎずに使う。
